# Домашнее задание

## Приведите 2-3 примера использования ClickHouse в компаниях на рынке

1. Я предполагаю, что ClickHouse мог бы эффективно использоваться в таких компаниях как Netflix / Spotify, для того, чтобы строить аналитику по пользователям. С помощью него, например, можно было бы строить статистику по трендам месяца или формировать персональные отчёты пользователя в виде stories (например "За год вы слушали музыку целых x часов", или "Ваш самый любимый трек года - X. Вы слушали его N раз.")
2. Вторым примером использования может применение ClickHouse в сфере ИБ (информационная безопасность) и мониторинга инфраструктуры. Мы могли бы собирать нормализованные метрики серверов, логи IPS / IDS систем, firewall'ов и прочих средств в инфраструктуре и строить по ним дашборды для команды SOC (Security Operations Center).

## К каким классам систем относится ClickHouse?

ClickHouse относится к системам класса OLAP (Online Analytical Processing).
